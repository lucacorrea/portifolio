# Urbanix ERP — Protótipo HTML

Protótipo navegável para demonstração de um sistema integrado de construtora, incorporadora e imobiliária.

## Stack do protótipo
- HTML5
- CSS3 customizado
- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Chart.js 4.5.1
- JavaScript Vanilla
