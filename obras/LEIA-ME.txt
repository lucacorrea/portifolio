OBRAS360 — PÁGINAS HTML INDIVIDUAIS

Este pacote contém 11 arquivos HTML, um para cada opção do menu:
- index.html (Painel geral)
- obras.html
- ordens-de-servico.html
- planejamento.html
- fiscalizacao.html
- projetos-e-documentos.html
- orcamentos-e-medicoes.html
- materiais-e-estoque.html
- predios-publicos.html
- protocolos.html
- relatorios.html

A pasta assets contém o CSS e JavaScript compartilhados.
Mantenha a estrutura de pastas ao publicar no servidor.
Abra index.html para iniciar o sistema ou qualquer outro HTML para abrir
diretamente o módulo correspondente.

Observação: são telas demonstrativas. Os dados e ações ainda não estão
conectados ao PHP/MySQL.
