OBRAS360 — Sistema PHP de gestão de obras e planejamento — Coari/AM
==================================================================

ESTA É UMA IMPLEMENTAÇÃO PHP COM BANCO, NÃO UM SITE HTML PARA ABRIR COM DUPLO CLIQUE.

1. REQUISITOS
   • PHP 8.2 ou superior com PDO SQLite (ou PDO MySQL), OpenSSL, fileinfo e Argon2id.
   • Pasta storage/ com permissão de gravação.
   • Um servidor PHP/Apache/Nginx configurado para apontar APENAS para public/.
   • Internet para o fundo do mapa OpenStreetMap; os demais módulos não exigem internet.

2. TESTAR RAPIDAMENTE NO WINDOWS (PowerShell ou CMD)
   Extraia o ZIP para uma pasta no computador, abra um terminal NESSA pasta.
   Se usar o PHP que acompanha o XAMPP, troque 'php' por C:\xampp\php\php.exe.

      copy .env.example .env
      php bin\setup.php --demo --email=administrador@exemplo.gov.br
      php -S 127.0.0.1:8000 -t public

   Em outro computador, use comandos equivalentes Linux/macOS:

      cp .env.example .env
      php bin/setup.php --demo --email=administrador@exemplo.gov.br
      php -S 127.0.0.1:8000 -t public

   O instalador EXIBE UMA ÚNICA VEZ a senha temporária aleatória.
   Acesse http://127.0.0.1:8000 no navegador e altere a senha no primeiro login.

3. PARA DADOS REAIS: NÃO USE --demo.
   Execute 'php bin/setup.php --email=seu-email-institucional' sem --demo.
   Prefira MySQL/MariaDB em ambiente com vários usuários. Configure DB_DRIVER=mysql,
   DB_HOST, DB_NAME, DB_USER, DB_PASSWORD no .env e habilite pdo_mysql no PHP.
   Consulte o README.md para criar o banco, instalar e implantar com segurança.

4. PASTAS
   public/              Arquivos que o navegador pode acessar.
   app/Controllers/     Ações HTTP e fluxos de cada módulo.
   app/Core/            Segurança, autenticação, banco, repositórios e validação.
   app/Services/        Exportações, anexos e movimentações.
   app/Views/           Telas HTML com marcação PHP, separadas da lógica.
   config/modules.php   Configuração de campos, telas e estados.
   database/mysql.sql   Todas as tabelas MySQL/MariaDB.
   database/sqlite.sql  Todas as tabelas SQLite.
   bin/                 Scripts de instalação, testes e manutenção.
   docs/                Segurança e roteiro de testes.

5. IMPORTANTES LIMITAÇÕES
   • Usuário e senha precisam ser criados no instalador; não existe senha fixa.
   • PDF é gerado usando Imprimir > Salvar como PDF no navegador.
   • CSV, Excel XLSX e GeoJSON são gerados por endpoints autenticados.
   • Mapas exigem rede para carregamento dos mapas-base externos.
   • Nenhum dado fictício equivale a obra, contrato ou coordenada oficial.
   • É necessária homologação técnica, jurídica e de segurança antes de uso oficial.

Para o guia detalhado, leia README.md e docs/TESTES.md.
